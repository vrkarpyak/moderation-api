Сервис модерации объявлений на Python и FastAPI. Он принимает данные объявления и возвращает true, если есть нарушение, или false, если нарушений нет.

Проверка простая: у верифицированного продавца объявление считается корректным независимо от количества изображений. У неверифицированного продавца должно быть хотя бы одно изображение. Если изображений нет, сервис возвращает true. Название, описание и категория пока не влияют на результат.

seller_id, item_id и category должны быть больше нуля, а images_qty не может быть отрицательным. Название и описание не должны быть пустыми. Пробелы по краям строк удаляются. Строки из одних пробелов, null и лишние поля не принимаются. Типы проверяются строго: например, строка "123" вместо числа вызовет ошибку.

При успешной проверке сервис возвращает статус 200 и одно значение true или false. Если в запросе неверные данные или не хватает обязательного поля, возвращается статус 400 со списком ошибок в поле detail. При внутренней ошибке возвращается статус 500 и ответ {"detail": "internal server error"}. Подробности такой ошибки записываются в лог сервера.

GET / возвращает {"message": "Hello World"} и позволяет проверить, что сервис запущен.

Код разделён на несколько файлов. В main.py создаётся приложение и обрабатываются ошибки. В schemas.py описаны входные данные. Обработчик из routers/predict.py передаёт их в services.py, где находится правило проверки. Затем результат сохраняется через repository.py.

Репозиторий хранит последнее предсказание для каждого item_id в обычном словаре. После перезапуска сервиса данные теряются.

Тесты находятся в папке tests. Чтобы запустить их, выполните из папки проекта с активированным виртуальным окружением:

python -m pytest -q

Тесты проверяют разные варианты модерации, валидацию данных, сохранение результата и обработку ошибок сервиса и репозитория. Для похожих случаев используется параметризация.
