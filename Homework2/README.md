Здесь собраны задачи на асинхронную работу и потоки.

В первой задаче сравниваются разные способы получения цен из магазинов: по очереди, одновременно, с таймаутом и с ограничением числа запросов. Во второй исправлена блокировка, из-за которой письма отправлялись по одному.

В третьей задаче реализован LRU-кеш, которым могут пользоваться несколько потоков. Когда кеш заполняется, он удаляет запись, к которой дольше всего не обращались.

В бонусной задаче сделан небольшой планировщик на генераторах. Он переключается между задачами, учитывает задержки и позволяет одной задаче дождаться результата другой.
