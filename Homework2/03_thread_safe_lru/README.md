Это LRU-кеш с ограниченным количеством записей. Он хранит пары из ключа и значения и запоминает порядок обращений к ним.

Добавление новой записи, обновление значения и успешное чтение делают ключ самым недавно использованным. Если места не хватает, удаляется ключ, к которому дольше всего не обращались.

Если ключа нет, чтение возвращает переданное значение по умолчанию или None. Проверка наличия ключа и получение размера кеша не меняют порядок записей. Вместимость задаётся при создании и должна быть не меньше единицы.

Данные хранятся в OrderedDict. Все операции защищены одним общим RLock, поэтому несколько потоков могут обращаться к кешу, не вмешиваясь в незавершённые операции друг друга.
