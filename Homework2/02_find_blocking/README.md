Код имитирует рассылку писем нескольким пользователям. Для каждого пользователя формируется текст письма, а ожидание ответа почтового сервера заменено задержкой.

Раньше эта задержка блокировала поток, в котором работал event loop. Пока одно письмо ожидало отправки, остальные корутины не могли продолжить работу. Поэтому письма уходили по очереди, хотя рассылка запускалась через gather.

Теперь задержка асинхронная и передаёт управление event loop. Остальные письма могут обрабатываться в это время, поэтому рассылка четырём пользователям занимает примерно полсекунды. Другие корутины тоже продолжают работать во время ожидания.
