Код получает цены из нескольких магазинов. Настоящих запросов к сайтам здесь нет: для каждого магазина заранее заданы цена и время ответа, а ожидание имитируется асинхронной задержкой.

При последовательном опросе каждый запрос начинается после завершения предыдущего. При одновременном опросе запросы запускаются через gather, поэтому общее время примерно равно времени самого медленного ответа. В обоих случаях цены возвращаются в том же порядке, в котором переданы магазины.

В варианте с таймаутом у каждого магазина есть своё ограничение по времени. Если ответ не получен вовремя, вместо цены возвращается None. Остальные магазины при этом обрабатываются независимо.

Ещё один вариант ограничивает число одновременных запросов с помощью семафора. Пока все свободные места заняты, следующие запросы ждут. Ограничение должно быть не меньше единицы.
