Здесь реализован небольшой event loop на генераторах. Планировщик по очереди выполняет готовые задачи, а задачи с задержкой откладывает до нужного времени.

Задача может дождаться результата другой задачи. На время ожидания она убирается из очереди готовых и не проверяет результат в цикле. Когда нужная задача заканчивается, планировщик сохраняет её результат и возвращает ожидающие задачи в очередь.

Если результат уже получен, ждать повторного выполнения не нужно. Одну задачу могут ждать несколько других, и каждая получит её результат.

Если готовых и спящих задач больше нет, но кто-то всё ещё ждёт, планировщик сообщает об ошибке deadlock. Это позволяет обнаружить ситуацию, в которой выполнение не может продолжиться.
